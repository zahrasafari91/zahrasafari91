 ## What I've Built
 
- Designed and deployed a real-time cardiac arrest risk prediction platform combining deep learning, ECG analysis, digital twins, and cloud-based monitoring
- Built machine learning systems from raw data to production, including data preparation, model development, evaluation, and deployment
- Developed AI applications powered by LLMs using RAG, agent workflows, and tool-calling to support intelligent decision-making
- Built cloud-native solutions with APIs, microservices, containers, and CI/CD pipelines to bring AI products into production
- Created full-stack applications that connect AI and machine learning services with intuitive user experiences
